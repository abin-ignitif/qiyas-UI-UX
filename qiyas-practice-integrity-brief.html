Screen 09A · Student pre-exam gate

Ask for honesty before the set begins.

One calm, sincere frame before every practice set: why an honest attempt matters, then one clear action to continue. Built from the provided demo screen, with its four rules and headline kept verbatim.

Resolution

Continue is the single action on the screen: one tap past the brief, straight into Screen 09. Green keeps its system meaning (state, correctness); the start action remains the ink primary shared by the whole exam flow.

Rejected

Shield, padlock, and exclamation-mark warning chrome. A fear-styled screen reads as accusation and invites dismissal; the demo's encouraging tone already earns attention.

Interactive preview

The brief, on both canvases.

Mobile keeps the demo's single column: emblem, headline, four rules, Continue. Desktop reads as a two-column brief — the ask on the left, the terms on the right — inside the same route. Arabic is primary; the app-bar-style language utility and the Language control stay in sync.

Flow

Where this sits.

The gate runs once per attempt. It is a pre-start interstitial, not a settings screen.

  • Entry

    “Start practice” on qiyas-student-dashboard.html (06) or qiyas-learning-library.html (08) routes here.

  • Accept

    “Continue” → qiyas-taking-test.html (09), practice mode.

  • Decline

    Topbar back chevron → student dashboard; the set never starts and no result is recorded.

Open gaps

Honest limits of this prototype.

  • Acceptance logging

    The tap on Continue is client-side only. Production should record an acknowledgement of the brief per attempt, attached to the submitted set.

  • Artwork dependency

    The top image is the exact practice_exam.svg supplied by the user, referenced from the project with a relative path; ship that file alongside the screen. Its palette is fixed artwork, so it does not recolor in dark theme.
