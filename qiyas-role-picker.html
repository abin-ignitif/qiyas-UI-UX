Decisions

Choosing the threshold deliberately.

The picker stays a threshold: it names the two audiences without adding account administration, marketing, or a network dependency.

2.1 Signup

No signup on this screen. A student cannot create an account, and a parent gets a proper signup path after choosing Parent.

Rejected alternative

Adding a “Create account” link here would add a third action and weaken the one-tap threshold.

2.2 Cached identities

After a role is used, “switch account” shows local names such as Aisha and Mum, plus a quiet “use a different account” path.

Rejected alternative

Showing only Student / Parent again makes shared-device switching slower and less human.

2.3 Parent mis-tap

Parent always routes to the parent login, where “Not you?” is visible but quiet and returns to this picker.

Rejected alternative

Using a confirmation dialog after tapping Parent adds friction to a recoverable mistake.

2.4 Skipping

The user cannot skip the picker on first run. Either role is always reachable; remembered roles, logout, and deep links bypass it deliberately.

Rejected alternative

A “Continue as…” default would create an accidental identity choice on shared devices.

Flow

One threshold, deliberate returns.

Role memory removes the daily gate. The picker returns only when the user explicitly changes identity or has no trusted role to restore.

01SplashResolve session, deep link, and remembered role.
02Remembered roleSkip picker and open Student or Parent login.
03Role pickerFirst launch, logout, or “not you?” only.
04LoginReturn to the intended destination after auth.

Deep links bypass this screen: invite and password reset already identify the destination. Session expiry preserves the destination and returns to the remembered role’s login.

Motion

The splash hands off, then stops.

The lockup lands at the unauthenticated shell’s optical centre. Role choices use only the existing quick and base transitions; nothing reaches signature.

Entry

Use the splash shared-element exit. The Arabic lockup remains the Arabic asset, and the physical travel mirrors with direction.

Reduced motion

Place the lockup at rest and use the system’s short cross-fade. The picker remains immediately actionable.

Engineer handoff

Every role-picker element maps to the system.

Role choice is composed from the canonical card, square-frame motif, button, feedback, and unauthenticated shell patterns. No new colour or radius is introduced.

Gap list

  • Role picker option componentThe system names the card and square-frame motif but does not define role-choice semantics, analytics, or cached-identity row behavior. Product engineering should codify this as a composed pattern.
  • Native identity storage contractThe visual surface is defined here; storage permission, encryption, and platform-specific identity labels remain implementation work.

Do / don’t

Do: let either role be reached in one tap.

Don’t: add signup, marketing copy, or a loading spinner to the threshold.
